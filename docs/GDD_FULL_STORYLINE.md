## 1. 游戏概述

| 项目 | 内容 |
|------|------|
| **游戏名称** | 齿轮黎明 |
| **英文副标题** | Dead Hour |
| **核心标语** | 一年。一座城市。一根中指上的伤口。 |
| **类型** | 文字冒险 · 分支叙事 · 生存模拟 |
| **主角** | 喻城（Yù Chéng）——职校机械系，23岁 |
| **时间跨度** | 第0天前48小时开始，共365个游戏日 |
| **结局数量** | 16个主线结局 + 1个隐藏结局 + 死亡成就系统 |
| **基调** | 文学惊悚 · 硬科幻异变 · 工业生存美学 |

### 1.1 核心承诺

这个游戏管理的不是资源，而是一个刚好也在管理资源的人。

所有机制系统——感染值、防御指数、倒计时、科技树——存在的意义是制造叙事压力，而非供玩家优化。游戏的胜利条件是活下来。游戏的**意义**在于你在这个过程中变成了什么。

### 1.2 叙事框架——见证者日志

游戏以喻城手写的一段话开场：

> *「我不知道有没有人会读到这里。但如果你读到了，说明这本笔记本最终没有和我一起消失。」*
>
> *「下面的内容，是我从第一天开始写下的。我尽量写得准确，不夸张，不美化。」*
>
> *「感染值这个词是裴嘉应教我的。她说，给它命名，比不给它命名，好控制一点。」*

这个框架在整个游戏中持续存在。在时间跳跃的平静日子里，若 `wrote_journal = true`，玩家读到的是喻城的第一人称手写日志，而非旁白摘要。

**二周目继承机制：** 若上一周目触发了特定结局（见[第10章](#10-十六大结局与死亡成就)），本页开头会出现一行被铅笔划掉的文字。划掉的力度很重，但依然可以辨认。

## 2. 核心系统参考

### 2.1 数值系统总览

| 数值 | 范围 | 玩家可见 | 默认值 | 归零后果 |
|------|------|---------|--------|---------|
| `health` 生命值 | 0–20 | ✓ | 10 | 结局：`ending_death_health` |
| `morale` 士气 | 0–20 | ✓ | 10 | 结局：`ending_death_morale` |
| `leadership` 领导力 | 0–20 | ✓ | 0 | — |
| `stealth` 潜行 | 0–20 | ✓ | 0 | — |
| `trust` 信任 | 0–20 | 隐藏 | 5 | 派系崩溃事件 |
| `infection` 感染值 | 0–10 | 信号提示 | 0→1（场景101触发） | 结局：`ending_full_zombie` |
| `will` 意志值 | 0–10 | 信号提示 | 5 | 同士气归零 |
| `security` 防御指数 | 0–100 | ✓ | 0 | 危机场景触发 |
| `timeRemaining` 倒计时 | 0–12 | ✓ 倒计时 | 12 | 触发危机场景 |

### 2.2 感染值阈值与效果

```
infection 0–2   → 无任何提示
infection 3–4   → 文本提示：「右手中指隐约有些不对劲，说不上来。」
               → 解锁：异化视角（低级）
infection 5–6   → 文本提示：「皮下那种感觉越来越难以忽视。」
               → 状态面板出现：感染 · 扩散中
               → 解锁：异化视角（中级）+ 超频操作
infection 7–8   → 文本提示：「某些念头出现的方式开始让你感到陌生。」
               → 状态面板：感染 · 异变临界
               → 自动设置 flag: zombie_turning
               → 解锁：镜中第三人机制
infection 9     → 文本提示：「边界在模糊。你已经不确定，某些念头，是不是你自己的。」
infection 10    → 自动设置 flag: full_zombie → 立即触发 ending_full_zombie
```

### 2.3 意志值阈值与效果

```
will >= 8 AND infection 3–7  → 自动设置 flag: superpower_awakening
                             → 状态面板：意志 · 觉醒临界
will <= 2                    → 状态面板：意志 · 濒临崩溃
will = 0                     → 触发士气崩溃（同士气归零结局）
```

### 2.4 防御指数标签

```
0–19    → 不设防
20–49   → 基础加固
50–79   → 相当安全
80–100  → 钢铁要塞  ← 若 zombie_turning = true，「反锁」讽刺结局可触发
```

### 2.5 变异路线判定

每次场景跳转后自动评估：

| 路线 | 条件 |
|------|------|
| `survivor` 幸存者 | infection < 3，或 infection < 5 且 will >= 6 |
| `awakening` 觉醒 | infection 3–7 且 will >= 8 |
| `turning` 异变 | infection >= 8 |
| `zombie` 完全异化 | infection = 10 |

## 3. 新增机制详解

### 3.1 超频操作（Overclocking）

**设计理念：** 感染值不是被动积累的惩罚数值，而是可以主动支出的**危险资本**。

**机制说明：**

在白天行动轮或深夜突发事件中，当 `infection >= 5` 且 `superpower_awakening = true` 时，部分选项旁会出现红色标注：

```
【普通】用电焊机加固大门（耗时 3小时，防御指数 +10）
【⚠ 超频】消耗感染值 +1，触发「血肉焊接」——精准感知金属应力点，
         瞬间完成焊接（耗时 0小时，防御指数 +30）
```

**超频选项的代价结构：**

| 超频类型 | 感染值代价 | 效果 | 风险 |
|----------|-----------|------|------|
| 血肉焊接 | infection +1 | 防御指数 +30，耗时归零 | 若 infection 因此达到8，自动触发 zombie_turning |
| 心率扫描 | infection +1 | 探查门后情况，获取敌方位置信息 | will -1 |
| 金属直感 | will -1 | 找出搜刮物品的最优路线，物品获取量+50% | 无感染代价，但会产生人格漂移日志 |
| 感知共鸣 | infection +2 | 短暂感知大范围尸群位置（地图级）| 极高风险，偶尔触发「白大褂」存在感 |

**超频的叙事意义：**

每次使用超频，该天的日志（若 `wrote_journal = true`）会有一行用不同力度写下的字：

> *「今天我用了。不得不用。结果是对的。」*
> *（下面有什么被划掉了，划了很多次。）*

**超频与裴嘉应笔记本的交叉：** 超频使用记录在她的临床观察中有对应条目（见3.2节）。玩家过度使用超频，会推高笔记本里「样本A」的危险评级。

---

### 3.2 裴嘉应的笔记本——实时互动机制

**设计理念：** 她的笔记本是游戏的第二视角，是玩家在第一人称之外唯一能看见自己的地方。

**笔记本获取方式：**

| 方式 | 条件 | 获取内容 | 后果 |
|------|------|---------|------|
| 主动告知（喻城主动坦白感染） | 第95–120天内选择 | 完整笔记，实时更新 | trust +3，`pei_knows_infection = true` |
| 偷看（潜行） | stealth >= 4，整备阶段行动 | 当前已写条目，但裴嘉应察觉概率20% | 若被发现：trust -3，触发对话事件 |
| 翻房间（信任消耗） | trust >= 7，整备阶段行动 | 当前已写条目 | trust -1/次 |
| 她主动出示（对话触发） | `pei_confrontation_done = true` | 全部条目 | 根据内容产生不同情感影响 |
| 她的遗物（她死亡后） | `pei_alive = false` | 全部条目，但最后一页未完成 | 解锁隐藏结局「记录者」 |

**笔记本内容的动态生成规则：**

笔记本条目根据玩家前1–3天的实际行为动态生成。以下是几组示例对照：

---

**若玩家昨天超频使用了两次：**

> *「样本A今日使用异能辅助两次。第二次结束后，右手指腹静脉可见异常充血，持续约四分钟。」*
> *「他试图用袖子挡住我。」*
> *「真是个蠢货。」*

---

**若玩家连续三天未休息（`excessive_exertion = true`）：**

> *「连续工作72小时，右手中指皮下黑斑扩大约0.3毫米。」*
> *「问他睡得怎么样，他说'还行'。」*
> *「我记录了他说话时眼皮的抖动频率。那不叫'还行'。」*

---

**若玩家选择了帮助陌生人（`helped_stranger = true`）：**

> *「今天他帮了一个不认识的人。没有要求任何回报。」*
> *「我不知道这说明他感染值还在他的控制下，还是病毒对道德判断没有优先破坏。」*
> *「希望是前者。」*

---

**若玩家连续使用超频且 infection >= 7：**

> *「样本A今日在我面前将一根工字钢徒手弯曲了约15度。」*
> *「他问我有没有看见。」*
> *「我说没有。」*
> *「我不确定这是不是错的。」*

---

**若玩家在Day 360选择了自我牺牲（E-1结局路线）：**

> *「临床观察·样本A，最终条目。」*
> *「他说，这是最合理的决定。」*
> *「从工程学角度来说，他是对的。」*
> *（下面空白。空白了很长。）*
> *「我希望他知道我从来没有只是在观察他。」*

**笔记本的叙事价值：** 玩家为了看裴嘉应怎么记录自己，会主动尝试各种极端的生存作息和行为组合。她的语言冷静、医学化，偶尔出现人格漏洞——这种「傲娇式关心」是游戏最强的情感钩子之一。

### 3.3 异化视角（Depraved Insight）

**设计理念：** 高感染值不只是风险，它也是一种独特的信息获取方式。

**机制说明：**

当 `infection >= 3` 时，某些场景中的普通探索选项旁会出现第二个选项，括号标注「（异化感知）」：

```
【普通】尝试打开那扇紧闭的铁门。
【（异化感知）infection >= 3】你听到了门后的东西。
         心跳。不规则，约140次/分。停顿的节奏是人类的，但间距不是。
         门后有两个。其中一个没有移动过。
```

**异化视角的三个级别：**

| 级别 | 解锁条件 | 能感知的信息 |
|------|---------|------------|
| 低级感知 | infection >= 3 | 门后生物数量、大致移动状态 |
| 中级感知 | infection >= 5 | 具体位置、心跳节律、是否为变异个体 |
| 高级感知 | infection >= 7 且 superpower_awakening | 可感知「白大褂」的存在，以及它是否在注意你 |

**叙事规则：**

- 异化视角的文字风格始终是**技术性的、冷静的**，不使用恐怖小说语言
- 感知到的信息不一定有利——有时结果是「门后有十七个，而且都在等待」
- 若同时拥有「高级感知」，偶尔会在探索场景末尾出现一行括号文字：
  > *（某个地方，一种你无法命名的东西感知到了你正在使用这个能力。它没有做任何回应。）*

### 3.4 垃圾佬改装系统（Junk Collector）

**设计理念：** 让工业垃圾变成满足感的来源，把黄昏整备阶段从资源分配变成实验室时间。

**搜刮可获得的工业废料（新增物品）：**

| 物品 | 获取途径 | 堆叠 |
|------|---------|------|
| `copper_wire` 铜线卷 | 废弃建筑、车辆 | 可堆叠 ×10 |
| `car_battery` 废旧电瓶 | 停车场、报废车辆 | 可堆叠 ×3 |
| `chain_drive` 摩托车链条 | 废品站、修车铺 | 可堆叠 ×5 |
| `blade_scrap` 废车床刀片 | 工厂、机械厂 | 可堆叠 ×5 |
| `radio_chip` 老收音机芯片 | 废弃民居 | 可堆叠 ×3 |
| `valve_gear` 旧阀门齿轮 | 工厂、水厂 | 可堆叠 ×4 |
| `glass_fuse` 玻璃保险丝 | 电器店、变电站 | 可堆叠 ×5 |

**改装配方示例：**

| 配方 | 所需材料 | 效果 | 解锁条件 |
|------|---------|------|---------|
| 货车车头破甲撞角 | 铜线卷 + 废车床刀片 + 货车钥匙 | 驾车场景时解锁「冲撞通路」 | `truck_key_found = true` |
| 高压电栅栏控制器 | 废旧电瓶 + 铜线卷 + 玻璃保险丝 | 防御指数每日自动 +2 | `base_factory = true` |
| 强化版角磨机 | 摩托车链条 + 废车床刀片 | 武器伤害提升，解锁新战斗选项 | — |
| 收音机信号放大器 | 老收音机芯片 + 铜线卷 + 阀门齿轮 | 收音机搜索范围扩大，可接收更远的频道 | `radio` 在物品栏 |
| 中指感应手套 | 铜线卷 + 玻璃保险丝 + 废旧电瓶 | 超频操作感染值代价 -1 | `superpower_awakening = true` |
| 应急发电机 | 废旧电瓶 ×2 + 阀门齿轮 + 铜线卷 | 停电事件中维持基地功能 | 任意据点 Tier 2 解锁后 |

**改装的叙事语言：**

每个改装完成后有一段一到两句的完成描述，始终使用喻城的技术性语言：

> *你把链条压进刀片槽里，用铜线缠了四圈，两端点焊固定。这东西按理说不应该能用——但你测试了一下，转速和噪音都在可接受范围内。*

### 3.5 手写日志收集与二周目继承（NG+）

**设计理念：** 死法也是一种收藏品。黑色幽默是继续游戏的动力。

**日志卡收集：**

当 `wrote_journal = true` 时，每个重要游戏日产生一张日志卡（Journal Card）。日志卡在结局界面后可回顾，格式如下：

```
┌─────────────────────────────────┐
│  第 23 天                        │
│                                   │
│  还在焊接。食物够。中指今天        │
│  没什么感觉，我不确定这是不是好事。 │
│                                   │
│  第 27 天                        │
│                                   │
│  裴嘉应问我睡得怎么样。           │
│  我说还行。                       │
└─────────────────────────────────┘
```

**死亡成就系统（Death Achievement Wall）：**

每个坏结局（BE）触发后，死亡界面不显示「游戏结束」，而是显示：

```
╔══════════════════════════════════════╗
║        成就解锁                       ║
║                                       ║
║  「世界上最安全的棺材」               ║
║                                       ║
║  你把门焊得太好了。                   ║
║  以至于没有任何东西能从里面出去。     ║
║  这是一个工程学上无懈可击的解决方案。 ║
║                                       ║
║  喻城  第365天  感染值: 8  防御: 100  ║
╚══════════════════════════════════════╝
```

**各坏结局成就名称（示例）：**

| 结局 | 成就名称 | 一行黑色幽默评语 |
|------|---------|----------------|
| BE-2 自缚钢铁巨兽 | 「世界上最安全的棺材」 | 防御指数100。关得很好。也关得太好了。 |
| BE-1 极寒无声熄火 | 「工程问题需要足够的时间来解决」 | 他在第47天因体温过低停止了运作。他的工具箱保持得很干净。 |
| BE-3 第364天功亏一篑 | 「统计学上的悲剧」 | 差一天。概率上不太可能，但确实发生了。 |
| 完全异化 | 「宿主已不再使用此账户」 | 感染值已满。意志值归零。设备控制权移交。 |

**二周目继承机制（NG+ Legacy Lines）：**

根据上一周目触发的结局，第一页日志出现一行被划掉的铅笔字：

| 上一周目结局 | 划掉的文字 |
|------------|----------|
| BE-2 自缚钢铁巨兽 | *~~门，其实不用焊得那么死……~~* |
| BE-1 极寒熄火 | *~~应该早点去超市的。~~* |
| 完全异化 | *~~某些选项，不要选。~~*（字迹歪斜） |
| 记录者（好结局） | *~~这本笔记本最后没有和我一起消失。——感谢你。~~* |
| 新人类领袖 | *~~她说信号来自东南方。~~* |

### 3.6 镜中第三人（The Mirror Mechanic）

**设计理念：** 「白大褂」的恐怖感不来自它的攻击性，而来自它的理解能力。

**触发条件：** `infection >= 7`（`zombie_turning` 已激活）且处于第四阶段（Days 271+）

**机制描述：**

在基地遭受围攻的深夜，白大褂不直接进攻。玩家在监控场景、反光钢板场景或窗口窥视场景中，会看到一个画面：

> *你透过监控摄像头的模糊画面，看到围城的死者群后面，有一个穿白大褂的身影站着不动。*
>
> *它在做什么？*
>
> *它在——擦拭它手上的什么东西。动作和你今天下午擦拭钳工台的动作一模一样。*
>
> *手腕旋转的角度。擦拭的次数。停下来确认的时机。*
>
> *一模一样。*

**三种反应选项（固定）：**

```
【A】关闭监控。你不想继续看了。
     → morale -2, will +1（「我知道它在那里」的清醒感）

【B】继续观察，记录它的行为模式。
     → will +2, infection +1（使用了异化感知）
     → 若 wrote_journal = true：解锁专项日志条目

【C】（若 zombie_signal_received = true）
     对它做出同样的动作。
     → 触发「信号互通」事件，修改多个Phase 4结局的可用性
```

**裴嘉应笔记本的镜中人条目（若玩家有笔记本访问权）：**

> *「第298天，深夜。样本A在监控室里待了42分钟。」*
>
> *「我查了录像。」*
>
> *「白大褂在做什么，他已经知道了，他只是不敢写进日志。所以我来写。」*
>
> *「我的理论是：它不是在指挥丧尸。它是在通过喻城的右手中指，学习人类使用工具的逻辑。它是一面镜子。」*
>
> *「我不确定这个理论是否正确。」*
>
> *「我更不确定这个理论正确时，意味着什么。」*

**镜中人机制的叙事功能：** 将恐怖感从「丧尸会咬人」升华为「它在复刻你的工业逻辑，它想取代你」。高感染值玩家会在镜中看到自己正在成为什么，低感染值玩家会看到自己可能会成为什么。

### 4.2 裴嘉应（全程同伴）

| 属性 | 内容 |
|------|------|
| 年龄 | 22岁 |
| 背景 | 实习护士，社区医院 |
| 核心特质 | 有条理的观察者。她把一切都记下来。 |
| 致命缺陷 | 把悲伤分区存放，直到某天它们同时爆炸 |
| 叙事功能 | 命名喻城拒绝命名的事物。她的研究笔记是同一段事件的第二镜头。 |

**四阶段完整弧线：**

#### 第一阶段（第1–60天）：患者

裴嘉应在第一阶段以创伤幸存者的身份存在，而非主动角色。她的生还状态完全取决于第一章的玩家选择。

**救援条件：**

| Phase 1 关键 Flags | 她的状态 | 效果 |
|-------------------|---------|----|
| `pei_status_hidden` | 稳定，躲在器械库 | 身体状况良好；携带医疗物资加入 |
| `pei_status_trapped_outside` | 腿部扭伤，躲在对面面包房 | 带伤加入；前30天 health 有惩罚 |
| `pei_status_injured_lost` | 危重；第45天后搜索才能找到 | 带创伤加入；morale 惩罚持续至第二阶段 |
| 第60天前未找到 | — | `pei_alive = false`；多个结局永久关闭 |

**第一阶段关键场景：**

*第7天——出租屋的台阶*

这是第一阶段最长的场景。喻城找到她，或者没有找到。场景以她们俩站在医院窗口看城市结束。一段沉默的叙述。然后她说：

> *「我们去哪里？」*

#### 第二阶段（第91–180天）：研究者

安置在据点之后，裴嘉应的护士背景开始发挥作用。她治疗NPC伤病，并——悄悄地，没有告诉喻城——开始记录在他身体里扩散的感染。

**关键发展：** 大约第120天，她开始一本名为「临床观察·样本A」的笔记本（见3.2节的完整互动机制）。

**感染秘密的张力：**

| 情景 | 触发条件 | 后果 |
|------|---------|------|
| 喻城主动坦白 | 第95–120天内选择 | `pei_research_begun = true` + trust +3；她协助管理感染 |
| 他找到笔记本并承认 | 玩家主动搜查后选择坦白 | 紧张但诚实；trust +1 |
| 她发现并质问（对峙） | 第150天前未处理自动触发 | `pei_confrontation_done = true`；trust -3；持续30天的疏远 |
| 双方始终沉默 | 两人都未提起 | 她的研究不完整；科学类结局关闭或降级 |

#### 第三阶段（第181–270天）：科学家

裴嘉应此时是幸存者群体中科学价值最高的人。其他派系觊觎她。

**第230天——被挟持危机（里程碑）**

某一派系（军方残部或劫匪联盟，取决于关系Flags）将裴嘉应作为人质。救援选项：

- 支付资源赎金：security -20，安全赎回
- 喻城领导力谈判（需 leadership >= 12）
- 使用超频能力（`superpower_awakening = true`时的专属场景）
- 放弃：`pei_alive = false`（永久关闭所有依赖她的结局）

救回后，她变了。第三阶段是她停止管理自己的悲伤分区的时候。她告诉喻城她在研究中发现了什么——不全是坏消息。

#### 第四阶段（第271–365天）：变量

| 进入第四阶段时的状态 | 她的角色 | 开启的结局 |
|-------------------|---------|-----------| 
| 存活 + 研究完整 + 感染已坦白 | 科学类结局的共同主角 | A-2，E-1，B-2 |
| 存活 + 研究不完整 | 情感支撑；开启人类类结局 | A-1，G-2，H-1 |
| 死亡，笔记本留存 | 遗物驱动叙事 | 记录者（隐藏结局） |
| 死亡，笔记本未留存 | 缺席塑造结局 | 不开启额外结局；轻微改变所有结局的语调 |

**裴嘉应的个人结局：** 她没有专属结局画面。但除了完全异化路线以外，每一个结局的最后一句话都提到她，以某种形式。哪怕在最坏的结局里，喻城也记得：是她给那件事命了名。

## 5. 日常循环设计

### 5.1 四段式游戏日

每个游戏日分为四个阶段。并非每天都需要玩家输入——平静日使用「时间跳跃卡」。但结构始终在后台运行。

```
清晨（情报与结算）
  → 计算前一晚的资源消耗（食物、水）
  → 应用日常感染值变化（基于当前状态）
  → 解算夜间事件（若有）
  → 收音机广播（若物品栏有收音机）
  → 若 wrote_journal = true：生成当日日志卡

白天（主行动轮）← 玩家选择点
  → 选择一项行动：
       【建造/加固】    → security 变化，时间消耗
       【外出搜刮/推进主线】  → 获取物品，健康风险，场景事件
       【外交/研究】    → trust 变化，NPC关系，Flag推进
       【休息】         → health/morale 恢复，风险最低
       【改装工坊】     → 消耗废料，制造装备（见3.4节）

黄昏（整备阶段）
  → 自动计算食物与水的分配
  → 改装操作（若材料足够且相关NPC在场）
  → 裴嘉应对话窗口（每个阶段出现3–4次）
  → NPC事件（随机，根据阶段和Flags加权）
  → 若有权限：裴嘉应笔记本偷看窗口

深夜（突发事件）
  → 通常平静（70%概率：无事，仅日志条目）
  → 事件池（30%概率：丧尸探查、NPC危机、感染症状、记忆/梦境）
  → 感染值高的深夜：独特的梦境序列
  → infection >= 7 的深夜：可能触发「镜中第三人」场景
```

### 5.2 时间跳跃卡

里程碑事件之间的平静期通过时间跳跃卡压缩时间，无需玩家逐日操作。

**两种类型：**

**旁白卡**（`wrote_journal = false`时）：

> *第23天到第31天，喻城在工厂里每天重复着同样的动作：焊接、巡逻、吃东西、睡觉。裂缝里的风越来越冷。中指的感觉没有恶化。他没有告诉任何人这句话。*

**日志卡**（`wrote_journal = true`时）：

> *第23天。还在焊接。食物够。中指今天没什么感觉，我不确定这是不是好事。*
>
> *第27天。裴嘉应问我睡得怎么样。我说还行。*
>
> *第31天。今天外面有声音，不像风。*

日志卡用喻城的声音写就，使用手写体字体，语气平实，信息密度更高——他会把不愿意说出口的事情写进日志。

## 6. 第一阶段·血色之冬（第1–90天）

**主旨：** 极度压抑、物资匮乏、物理防御为核心、确立身体机制。

**基调参考：** 原著小说前六章。克制，贴近，实际。没有英雄主义，没有演讲。

---

### 第一章：最后一个正常的傍晚（开始前48小时）

*对应场景文件：scene_101 至 scene_108*

**核心事件线：**

- 中指划伤（`onEnter: infection = 1`）——喻城从废品站买来的电焊机的主人是谁，这个问题游戏永远不会直接回答
- 《城市晚报》上那三则失踪通稿
- 裴嘉应的电话与信号中断
- 加固的那个夜晚
- 零时：身体开始改变

第一章的所有选择直接影响第一阶段的起始数值分布。

---

### 第二章：堡垒周（第1–7天）

**第1–3天：** 公寓坚守。防御指数是一切。日常循环正式启动。

**第1天清晨：** 建立以下初始状态：
- 来自第一章选择的当前防御指数
- 第一次资源盘点
- 第一次收音机信号（若有收音机）：静电，片段，一个声音在句子中间停止

**第3天深夜：** 第一次丧尸探查。门守住还是守不住，取决于防御指数。

| 第3天防御指数 | 夜间事件 |
|-------------|---------|
| 0–19 | 门局部突破。health -3，场景：一只手从缝隙里伸进来。 |
| 20–49 | 持续抓挠。未突破。morale -2。 |
| 50–79 | 未突破。楼上传来声音。 |
| 80–100 | 完全安静。比噪音更令人不安。 |

**第5天：** 若 `infection >= 3`，触发第一个感染症状场景。

> *镜子里的你看起来有什么不对劲。你说不清楚是什么。你没有在日志里写这件事。*

---

**第7天：强制出门（里程碑）**

食物耗尽，或防御崩溃，或喻城决定主动离开。离开方式影响后续：

| 离开方式 | 条件 | 后果 |
|---------|------|------|
| 正门直闯 | 无 | health -4，潜行本阶段 -1 |
| 窗口攀水管 | stealth >= 2 | health -2，发现城市另一个视角 |
| 驾陈师傅的货车 | `truck_key_found = true` | health ±0，开启载具场景线 |
| 等到第14天 | security >= 60 | 可多等两周；错过部分第8–14天事件 |

---

### 第三章：死城（第8–30天）

**核心目标：** 抵达城东，确认裴嘉应的状态。

**关键场景：**

*第10天——超市*

第一个大规模搜刮场景。有其他幸存者在场。尚未敌对——所有人都还在处理发生了什么。

选择：帮助一个受伤的家庭，还是趁他们不注意拿走他们的物资？

Flag: `helped_stranger = true/false`——影响第二阶段NPC士气与trust数值。

---

*第15天——广播*

若物品栏有收音机，接收到一个政府声音播报坐标。播报听起来不像直播。坐标指向工业区——即第二阶段工厂据点的位置。

Flag: `heard_government_broadcast = true`

---

*第22天——车队*

一辆军车经过。没有停。车厢里的一名士兵直视了喻城一眼。卡车侧面有一个红十字，上面用黑色漆掉了另一个符号。

这是有组织权威存在但不会来帮忙的第一个提示。

---

*第30天——医院入口（里程碑）*

**场景规模：** 全场景。医院可见，感染者可见，入口在中间。

| 入场方式 | 条件 | 解锁内容 |
|---------|------|---------|
| 正门直入 | 无 | 最快；最高健康风险 |
| 维修管道 | stealth >= 3 | 更安全；发现实验室物资 |
| 先观察再行动 | will >= 5 | 发现感染者巡逻规律；stealth +1 |

---

### 第四章：城东医院（第31–60天）

**基调：** 这是恐怖章节。医院不只是危险——它是**错的**。感染者在这里以更大的群体移动，随机性更低。

喻城和玩家都注意到了这一点。裴嘉应找到后有一个理论。她到第二阶段才会说出来。

**医院区域：**

| 区域 | 风险 | 获得物资 |
|------|------|---------|
| 急诊室 | 高 | 若找到急救箱：infection -1 |
| 三楼器械库 | 中 | 裴嘉应（若 `pei_status_hidden`） |
| 药房 | 中 | 抗生素（高感染值玩家关键） |
| 地下实验室 | 极高 | 郑博士留下的研究笔记（第三阶段前无法读取） |

---

*第45天——出租屋的台阶（里程碑）*

## 7. 第二阶段·铁血之春（第91–180天）

**主旨：** 建造、选择、成为。末日作为建筑项目。感染作为设计约束。

**基调：** 更少恐怖，更多重量。这里做出的决策有长期后果。日常循环变成管理节奏。

### 7.1 据点选址（第95天——里程碑）

游戏中影响最深远的单次选择。三个长期基地选项，对应不同的游玩风格，开启不同的第三、四阶段内容。

#### 据点A：废弃机械厂

*「这地方有三相电。有一台还能转的车床。地板够厚。」*

|------|------|
| 初始防御指数 | 15（现有结构） |
| 食物容量 | 低（无农业） |
| 科技潜力 | 最高 |

| 专属开启结局 | F-1，F-2，H-1 |

**机械厂科技树：**

```
第一层（第95–120天）：
  基础供电恢复 → 自动周界照明
  载具修复（若 truck_key_found） → 第三阶段载具场景
  焊接站升级 → 防御指数+15/行动（原为+8）

第二层（第121–150天）：
  高压周界电网 → 防御指数自动每日+2

第三层（第151–180天，需老许存活）：

  电气拦截网格 → 第三阶段围攻抵抗+40%
```

**机械厂专属玩法：** 机械改装实验室（第三层）允许喻城对自己的身体进行工程改造。这不是超自然的——这是对物理问题的工程解决方案。

**改造方案（每个消耗 health -2 和一个工坊行动日）：**

| 改造 | 效果 |
|------|------|
| 碳纤维指套（右手） | 感染值扩散 -1/天（永久） |
| 神经传导放大器 | stealth +3 |
| 结构应力读取器 | 仅在 `superpower_awakening = true` 时可用；增强感知能力 |

**工厂叙事氛围：** 工厂停产时，生产线上还摆着订单。是什么的零件，没有人知道。老许认出了规格书。他没有说是从哪里认出来的。


**防空洞叙事氛围：** 防空洞上次使用是在1970年代。有人留下了食物，至今仍可食用。墙上的日历是1978年的。红笔圈出的日期是十月的一个星期二。为什么圈这个日期，没有解释。

**防空洞专属玩法：** 外交路线。连珏知道政府相关派系的思维方式。她会谈判，即使喻城不想让她谈。

**农场叙事氛围：** 阿福的家族在这片地上生活了三代。他不谈自己的家人在哪里。他谈土壤pH值、霜冻日期和每年不需要种植就会自己回来的作物。他说，土地记得。

### 7.2 第180天——感染值第一次全面清算（里程碑）

无论何种据点，第180天都触发一个强制场景：喻城独自坐下，阅读每一个症状、每一次变化、每一次恢复。

**清算结果：**

| 第180天感染值（0–10量程） | 结局 | 锁定路线 |
|--------------------------|------|---------|
| 0–2 | 「伤口的影响，似乎消失了。」 | 幸存者路线 |
| 3–4 | 「没有消失。但它停下来了。」 | 幸存者或觉醒 |
| 5–6 | 觉醒异能全面激活 | **觉醒路线锁定** |
| 7–9 | 变异临界触发 | 异变路线；完全异化可能 |
| 10 | — | 立即触发 `ending_full_zombie` |

**若觉醒路线激活（infection 5–6，will >= 8）：**

一个独特场景。喻城在修理某样东西——一个铰链，一根管道——他的右手在眼睛之前找到了应力失效点。他感觉到金属中应力分布，就像感觉自己的心跳。他停下来。他把扳手放下。他坐在地板上，待了很长时间。

裴嘉应一小时后找到他在那里。她问他还好吗。他说他不知道。她坐到他旁边的地板上。两个人都没有站起来，待了一会儿。

## 8. 第三阶段·瘟疫之夏（第181–270天）

**主旨：** 熵。玩家建造的一切同时承受三个方向的压力：瘟疫、智慧尸群、其他人类。

**基调：** 恐怖回归，但形态改变。第一阶段是幽闭性的恐惧。第三阶段是四面八方的恐惧。威胁无处不在，有些还穿着人的脸。

---

### 8.1 三重威胁结构

**威胁一：瘟疫（第181–210天）**

旱季与酷暑。储存的肉类迅速腐败。水源遭受尸毒污染。基地内爆发疾病，每周一名NPC生病事件（morale成本，若无医疗支持可能死亡）。

日常附加消耗：食物 -1/天，水 -1/天。

反制方案：裴嘉应的医疗能力、抗生素储备、水净化（若已建造）。农场路线的水净化科技在此时是游戏中最有价值的设施。

---

**威胁二：尸潮领袖（第210–240天）**

*第215天——那件白大褂（里程碑）*

从安全距离看到领袖。医院病号服。在其他死者移动时它站着不动。它在看基地。若 `superpower_awakening = true`：在喻城看见它之前，他感觉到了它的注意。

尸群开始使用简单工具：

- 第220天：用捆绑在一起的管子做成的撞门器
- 第230天：它们等到黎明而非深夜发动攻击

裴嘉应笔记本条目（若玩家有访问权）：

> *「今天它等了。它在等什么？」*

游戏永远不回答这个问题。

---

**威胁三：人类派系（第241–270天）**

三个派系与玩家据点产生冲突：

| 派系 | 领袖 | 核心意识形态 | 初始立场 |
|------|------|------------|---------|
| 军方残部 | 徐宏上校 | 秩序高于一切 | 要求人口登记与资源审计 |
| 暴徒联盟 | 刀疤 | 武力即法律 | 第255天起公开敌对 |
| 政客联盟 | 市长助手林嘉雯 | 维持前末日合法性 | 提供带条件的保护协议 |

---

*第250天——抉择点9：楼道里的求救声*

12名幸存者——带孩子的家庭——在第三阶段走投无路来到基地。收留他们消耗食物与防御资源。拒绝他们消耗士气与信任。你的决定影响第四阶段。

---

*第230天——裴嘉应被挟持（里程碑）*

救援选项：支付资源、领导力谈判（leadership >= 12）、超频使用（专属场景）、放弃（永久关闭多个结局）。

---

## 9. 第四阶段·审判之秋（第271–365天）

**主旨：** 收束。这一年快结束了。每个选择现在都有复利。

**结构：** 探索减少，后果增加。第四阶段是游戏播放玩家过去270天所做决定的录音。

---

### 9.1 百日围攻（第271–330天）

尸群与至少一个人类派系同时或先后发动攻击。积累的防御指数在这里消耗。

**围攻力学：**
- 每天：security -3（攻击持续不断）
- 每10天：里程碑围攻事件（大规模攻击，选择防御方案）
- security 归零：基地沦陷 → 逃亡类或坏结局路线

**每位NPC的牺牲场景：**

老许守住发电机。阿福拒绝放弃种子库。这些场景简短，一段话，没有选项。玩家读到的是他们的早期决定带来了什么。

---

### 9.2 停火窗口（第330–360天）

一个派系提出条件。哪个派系以及条件内容完全取决于积累的关系Flags。

| 主导派系 | 提出的条件 | 接受后 | 拒绝后 |
|---------|-----------|-------|-------|
| 军方 | 服从权威，共享裴嘉应的研究 | A-2，G-1 | 最终决战 |
| 政客联盟 | 政治整合，联合治理 | G-2，B-1 | 分裂 |
| 白大褂信号 | 未知；裴嘉应的最佳猜测：「它想要边界」 | B-1，C-1 | 最终冲击 |
| 无（全部敌对） | 无停火可能 | 仅独行结局 | 围攻至第365天 |

---

### 9.3 最终选择（第360天——里程碑）

一个场景。没有时间压力。游戏中最长的后果文本。

玩家被告知他们建造了什么、谁还活着、他们的身体变成了什么、以及墙外是什么。然后一个选项出现。它不戏剧性。它很实际。戏剧性的选择都在更早之前做出了。

第360天的选择只是：当第365天来临时，你朝哪个方向站。

---

## 10. 十六大结局与死亡成就

### 10.1 结局判定矩阵

**轴X（感染路线）：**
- 幸存者：第365天 infection 0–4
- 觉醒：infection 5–7，will >= 7
- 异变：infection 8–9
- 异化：infection 10（在第365天前触发）

**轴Y（主导策略）：**
- 科学/秩序：`scientist_saved = true`，高研究Flags
- 机械：base_factory 或高改造数量
- 外交：大型NPC群体，高trust，派系协议
- 野路子：特定非常规Flag组合

---

### 幸存者路线（infection 0–4）

---

**A-1 · 凡人钢铁黎明**

> *「他们问我怎么活下来的。我说：我修了很多东西。」*

**触发条件：** infection <= 3，`survived_one_year`，`has_group`，`built_shelter`，leadership >= 12

喻城领导一个幸存者社区进入新的一年。伤口愈合得很干净。他还是原来的他——一个有良好空间推理能力、不擅长演讲的机修工。这个社区不需要演讲。他们需要供水系统继续运转。

若裴嘉应存活：她在写什么东西。还不肯说是什么。

**死亡成就变体：** 无（此为好结局）

---

**A-2 · 基因阻断剂**

> *「裴嘉应的笔记本最后一页是一个分子式。」*

**触发条件：** infection <= 3，`scientist_saved`，`pei_research_complete`，`pei_alive`

研究完成了。阻断剂不能治愈感染者——没有任何东西可以。但它能阻止健康的幸存者转变。郑博士以他一贯的平静说：够了。

喻城不是这个结局的主角。裴嘉应和郑博士才是。他守住了墙，让他们守住了显微镜。

---

**H-1 · 最强钉子户**（隐藏喜剧结局）

> *「他在第365天早上数了一遍食物。还剩三罐。比他预计的多一罐。」*

**触发条件：** infection <= 2，独行（无群体），security >= 80，`base_factory`，全阶段独活

喻城从未离开工厂。他的饮食高效，焊接高效，以数学般的精度活了下来。没有人知道他在这里。第365天他打开一罐食物，是和他公寓里零时前一样的品牌，他坐在工厂地板上，为了什么都不是，独自笑了一会儿。

这个结局里没有裴嘉应。但她给他的收音机还在工作台上，还能开机。

**NG+继承文字：** 无（此为独行结局，不产生遗产台词）

---

**G-1 · 替罪羊的远行**

> *「他们给了他物资和一个方向。」*

**触发条件：** infection <= 4，`survived_one_year`，派系对玩家群体敌对，接受流放条件

政客或军方派系决定喻城作为象征比作为一个人更有用。他得到物资和一个方向。他的群体被吸收。他离开了。

结局跟随他走了六个月。他在下一个山脊的另一边找到了什么。游戏在显示之前切断了画面。

若裴嘉应存活：她是这场交易的一部分。她在最后一天才知道这件事。

---

**G-2 · 废土割据**

> *「一个有墙壁、有武器、有只在墙内适用的规则的派系。」*

**触发条件：** infection <= 4，`survived_one_year`，`has_group`，劫匪联盟被吸收，leadership >= 15，trust < 5

喻城赢了，但他变成了他所逃离的东西：另一个有墙壁、有武器和有只在墙内适用的规则的派系。游戏没有作出评价。结局用和其他地方完全相同的实际语气描述他建造了什么。

里面很舒适。这就是恐怖所在。

---

**H-2 · 病毒的双向奔赴**

> *「宿主通过将自身逼至极限来耗尽了病毒。」*

**触发条件：** infection 2–3，第240天后特定Flag：`excessive_exertion`（连续18+个行动日不休息触发），health <= 4

身体通过几乎自我毁灭来对抗病毒。喻城还活着，但永久改变了——不是因为病毒，而是因为这一年。他从不连续睡超过三小时。他将永远不会了。

若裴嘉应存活，她的笔记本最终条目：

> *「样本A的感染值归零。原因不明。推测：宿主将病毒耗尽于自身的过激代谢。」*
> *「结论：宿主很蠢，但有效。」*

---

### 觉醒路线（infection 5–7，will >= 7）

---

**F-1 · 血肉苦弱，机械飞升**

> *「工厂的嗡嗡声围绕着他，一如既往。」*

**触发条件：** infection 5–6，`base_factory`，改造数量 >= 3，`superpower_awakening`

喻城已经一块一块地替换了足够多的自己，以至于他是什么这个问题已经变得真正不清晰。不是丧尸。也不是任何神话意义上的超人。是某种修理事物的速度比事物损坏速度更快的东西。工厂的嗡嗡声围绕着他，一如既往。

这是唯一一个结局中他的身体没有被提及的结局。他不再想这件事了。

基地幸存下来了。四十个人。发电机从未停止过一次。

**B-1 · 血肉停战协议**

**触发条件：** infection 5–6，`zombie_signal_received`，与尸群领袖外交解决，`pei_research_complete`

没有人知道停战是否成立。裴嘉应的研究表明领袖可能以不同于人类政治的时间线运作——看起来像协议的东西可能是别的什么。但攻击停止了。边界成立了。暂定的。

游戏以那个词结束：暂定。

像喻城这样的人还有其他的。比他预期的少，但比裴嘉应预期的多。她一直在追踪信号。他已经能感知到其中一些了。

这是唯一一个明确向前看的结局。它不解释接下来会发生什么。喻城也不解释。

### 11.3 内容写作五原则

**1. 每一天都有代价。**
时间消耗不是惩罚，是游戏告诉玩家生活需要时间的方式。不要让任何行动免费。

**2. 裴嘉应不是奖励。**
她的存在不会让事情变容易，只会让事情变得有意义。游戏中最难的场景应该涉及她在某件事上是对的。

**3. 感染从不自我宣告。**
永远不要写「你感觉到了病毒的力量」。
写「你在不看的情况下知道那颗螺丝已经松了」。
展示，不命名。

**4. 白大褂是不可知的。**
抵制解释它的冲动。每次它出现的场景都应该留下比关闭更多的疑问。裴嘉应的笔记本可以有理论。理论应该自相矛盾。

**5. 所有结局用同一种声音。**
每一个结局都用和开场场景相同的克制、实际语气写就。没有紫色散文，没有胜利主义，没有绝望主义。只是尽可能准确地，发生了什么。
